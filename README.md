# 🧭 Cargo Navigation

Навигатор в браузере (как Google Maps / Навигатор), который строит **самые быстрые маршруты с минимальными затратами на дорогу** и даёт управлять выбором дорог.

## Возможности

- **Реальные дороги** из OpenStreetMap (Overpass API), карта — Leaflet. Поиск адресов через Nominatim, точки можно ставить кликом/перетаскиванием, есть геолокация.
- **Платные / бесплатные дороги**: комбинировать оптимально · только бесплатные · предпочитать платные.
- **Типы дорог**: автомагистрали, шоссе, главные, второстепенные, местные, жилые улицы, дворы — включайте и отключайте.
- **Ограничения скорости**: не ездить по дорогам с лимитом ниже/выше заданного (из тега `maxspeed`), потолок скорости вашего авто.
- **Минимум затрат**: стоимость = `время × цена вашего часа + платные участки + топливо`. Ползунок «Быстрее / Баланс / Дешевле» меняет цену часа. Топливо считается с учётом скорости (на трассе расход выше).
- **Альтернативы на фронте Парето**: «самый быстрый», «самый дешёвый» и «оптимальный для ваших настроек» с разбивкой времени, платных дорог и топлива.
- **Навигация в пути**: пошаговые подсказки, голос (SpeechSynthesis), знак ограничения скорости, остаток пути/времени/расходов, автоперестроение при уходе с маршрута. Без GPS (и в демо) — симуляция движения.

## Android-приложение

Папка `android/` — приложение-оболочка (Java, WebView): то же веб-приложение из `web/` упаковано в APK и работает без CDN. Нативно добавлены геолокация (с запросом разрешения), голосовые подсказки через Android TTS и удержание экрана включённым во время навигации.

**Сборка APK**

- Через GitHub: вкладка *Actions* → *Android APK* → *Run workflow*; готовый `app-debug.apk` будет в *Artifacts*.
- Локально (нужны JDK 17 и Android SDK): `cd android && ./gradlew assembleDebug` → `android/app/build/outputs/apk/debug/app-debug.apk`. Либо откройте папку `android/` в Android Studio и нажмите Run.

Требуется Android 7.0+ (API 24). Для установки APK вне Play Market разрешите установку из неизвестных источников.

## Запуск веб-версии

```bash
npm start          # http://localhost:8080  (ES-модули требуют http, а не file://)
npm test           # тесты маршрутизатора
```

Кнопка **«Демо без интернета»** строит маршрут по встроенной сети (платная магистраль vs бесплатное шоссе vs местная дорога) — удобно, чтобы увидеть, как меняется выбор при смене настроек.

## Как это работает

| Файл | Назначение |
|---|---|
| `web/src/router.js` | A\* по графу; состояние «на платной дороге» для платы за въезд; перебор цены времени → фронт Парето; пошаговые инструкции |
| `web/src/osm.js` | Overpass-запрос (размер данных зависит от длины маршрута), разбор `highway/maxspeed/toll/oneway`, построение графа |
| `web/src/demo.js` | Демо-сеть |
| `web/src/app.js`, `web/index.html`, `web/style.css` | Интерфейс и режим навигации |
| `android/` | Android-оболочка (WebView + TTS + геолокация) |

В зоне ~800 м у старта и финиша мелкие улицы доступны независимо от фильтров, иначе нельзя было бы выехать со двора.

## Ограничения

- OpenStreetMap знает, **какие дороги платные, но не тарифы** — ставки (за км и за въезд) задаются в настройках.
- Навигация работает, пока приложение на экране (экран не гаснет); фонового сервиса геолокации пока нет.
- Нет данных о пробках: скорость = лимит × поправочный коэффициент по типу дороги.
- Публичный Overpass ограничивает объём: для очень длинных маршрутов (> ~150 км) мелкие дороги в середине не загружаются, остаются магистрали и главные; свыше ~600 км запрос отклоняется. Для продакшена стоит поднять собственный Overpass или готовый граф.
- Повороты и светофоры отдельно не учитываются.
