# 🧭 Cargo Navigation

Android-навигатор на **Flutter** для поездок по странам Евросоюза. Настроек нет: пользователь указывает только,
куда ехать, остальное приложение решает само.

## Как это работает

- **Интерфейс в духе Google Карт:** строка поиска «Куда едем?», старт от текущего местоположения, карточка маршрута
  с временем, расстоянием и стоимостью, кнопка «В путь», экран ведения (манёвр, знак ограничения скорости, время прибытия,
  карта по ходу движения, голосовые подсказки, перестроение при уходе с маршрута).
- **Выбор маршрута:** не кратчайший, а оптимальный по скоростному режиму с приоритетом бесплатных дорог. Платная дорога
  выбирается, только если экономит больше 1,5 минуты на каждый евро (`RouteProfile.mainLambda`). Альтернативы —
  самый быстрый и без платных дорог — показаны в карточке.
- **Стоимость дороги = только платные дороги:** плата за километр (Франция, Италия, Испания, Португалия, Хорватия, Греция,
  Польша) и виньетки (Австрия, Чехия, Словакия, Словения, Венгрия, Румыния, Болгария). Виньетка считается один раз на страну,
  по самому короткому сроку действия.
- **Только Евросоюз:** дороги стран вне ЕС отбрасываются при построении графа, опорная линия дальних маршрутов
  прокладывается в обход таких стран; точки вне ЕС отклоняются с пояснением.
- **Погода:** текущая погода вдоль маршрутов (Open-Meteo) снижает расчётную скорость и может поменять основной маршрут;
  в карточке показывается предупреждение и добавленное время.
- **Маршруты любой длины:** данные OpenStreetMap грузятся коридором вдоль пути кусками по ~150 км, расчёт идёт в фоновом потоке.

## Чего пока нет

- **Пробки, перекрытия и ремонты в реальном времени.** Для них нужен поставщик данных о дорожной обстановке (например,
  TomTom или HERE) и его ключ; бесплатного источника без ключа на всю Европу нет. Сейчас учитывается только то, что
  отражено в OpenStreetMap: дороги, закрытые для движения или строящиеся, в граф не попадают.
- Прогноз погоды на время проезда (используется текущая погода).
- Точные тарифы по участкам платных дорог и особые платные объекты.

## Сборка

Нужен Flutter 3.47+ и Android SDK.

```bash
flutter pub get
flutter test                  # маршрутизатор, страны и тарифы, дальние маршруты, погода, навигация, экран
flutter build apk --release   # build/app/outputs/flutter-apk/app-release.apk
```

На GitHub сборка идёт автоматически (*Actions → Android APK*); APK публикуется в релиз `apk-latest`.

## Ключ подписи (чтобы обновлять приложение, не удаляя его)

Android обновляет приложение поверх установленного, только если подпись совпадает. Пока ключ не задан, CI подписывает
APK временным ключом, который каждый раз новый, и приходится удалять приложение. Постоянный ключ создаётся **один раз**:

1. На своём компьютере (нужна Java) выполните `./tools/create-signing-key.sh` — он создаст файл ключа и напечатает 4 значения.
   **Сохраните файл ключа** (потеряете — придётся один раз переустановить приложение).
2. В GitHub: *Settings → Secrets and variables → Actions → New repository secret* — создайте секреты
   `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` со значениями из вывода скрипта.
3. Запустите сборку (*Actions → Android APK → Run workflow*). Дальше все сборки подписываются этим ключом, а номер версии
   растёт сам (`versionCode` = номер запуска), поэтому новые APK ставятся поверх старых.

Ключ намеренно **не хранится в репозитории**: иначе любой, кто видит репозиторий, мог бы выпускать «обновления» вашего приложения.
Первую установку после настройки ключа придётся сделать с удалением старой версии — один раз.

## Структура

| Путь | Назначение |
|---|---|
| `lib/core/` | граф дорог, поиск маршрута (A\* по времени и плате), страны и границы, модель платы, погода |
| `lib/engine/` | загрузка дорог (Overpass), короткие и дальние маршруты, обход стран вне ЕС, Open-Meteo, фоновый поток |
| `lib/ui/` | карта, поиск, карточка маршрута, ведение по маршруту |
| `assets/geo/` | границы стран Европы (Natural Earth 1:10m; собирается `tool/build_geo.py`) |
| `assets/tariffs/` | цены: `countries.json` (схемы стран) и файлы операторов (см. `tool/README.md`) |
| `test/` | тесты, в том числе синтетические сети через несколько стран |

## Ограничения

- Границы стран известны с точностью около километра, поэтому дорога считается «вне ЕС», только если уходит за границу
  глубже чем на ~1,5 км.
- Какие дороги требуют виньетку, определяется по классу дороги (магистрали и скоростные шоссе; в Румынии и Болгарии —
  ещё и главные дороги). Это приближение к правилам стран.
- Нет данных о пробках: скорость = ограничение × поправка по типу дороги × поправка на погоду.
- Публичные серверы Overpass, Nominatim, Open-Meteo и тайлы OSM — для умеренного использования.
