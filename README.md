# 🧭 Cargo Navigation

Android-навигатор на **Flutter** для поездок по странам Евросоюза. Настроек нет: пользователь указывает только,
куда ехать, остальное приложение решает само.

## Как это работает

- **Интерфейс в духе Google Карт:** строка поиска «Куда едем?», старт от текущего местоположения, карточка маршрута
  с временем, расстоянием и стоимостью, кнопка «В путь», экран ведения (манёвр, знак ограничения скорости, время прибытия,
  карта по ходу движения, голосовые подсказки, перестроение при уходе с маршрута).
- **Выбор маршрута:** не кратчайший, а оптимальный по скоростному режиму с приоритетом бесплатных дорог. Платная дорога
  выбирается, только если экономит больше 1,5 минуты на каждый евро (`RouteProfile.mainLambda`). Альтернативы —
  самый быстрый и без платных дорог — показаны в карточке.
- **Стоимость дороги = только платные дороги:** плата за километр (Франция, Италия, Испания, Португалия, Хорватия, Греция,
  Польша) и виньетки (Австрия, Чехия, Словакия, Словения, Венгрия, Румыния, Болгария). Виньетка считается один раз на страну,
  по самому короткому сроку действия.
- **Только Евросоюз:** дороги стран вне ЕС отбрасываются при построении графа, опорная линия дальних маршрутов
  прокладывается в обход таких стран; точки вне ЕС отклоняются с пояснением.
- **Погода:** текущая погода вдоль маршрутов (Open-Meteo) снижает расчётную скорость и может поменять основной маршрут;
  в карточке показывается предупреждение и добавленное время.
- **Маршруты любой длины** по ЕС — через серверы маршрутизации сообщества OpenStreetMap (см. ниже).

## Как строится маршрут

Маршрут считает сервер маршрутизации, а не телефон: у сервера уже есть дорожный граф всей Европы.

1. **Valhalla** ([FOSSGIS](https://valhalla1.openstreetmap.de)) — основной: русские подсказки, отметки платных участков
   и магистралей, вариант без платных дорог, альтернативы. Ограничение публичного сервера — 1500 км пути на запрос.
2. **Длинные маршруты** (больше ~1000 км по прямой или с обходом) делятся на участки. Точки стыка ставятся на общем
   маршруте от **OSRM** ([FOSSGIS](https://routing.openstreetmap.de), без ограничения длины), если он целиком в ЕС, иначе — на
   линии, проложенной по странам ЕС; точки привязываются к главным дорогам.
3. **Только ЕС:** если участок заходит в страну вне ЕС, дорога сразу за этой границей запрещается и участок
   перестраивается; если не помогло — участок идёт через частые точки линии по ЕС.
4. **Запасной вариант:** если Valhalla недоступен, маршрут строит OSRM. У него нет данных о платных дорогах, поэтому
   стоимость такого маршрута помечается как «не рассчитана».
5. **Стоимость** приложение считает само по странам вдоль линии маршрута: плата за км, виньетки (раз на страну),
   платные тоннели; платные участки без известной цены и паромы — предупреждения.

Проверка на реальных серверах: `dart run tool/live_check.dart` (Таллин → Тарту и Милан, Мюнхен → Милан,
Вена → Будапешт, Салоники → Загреб в обход Сербии, Лиссабон → Хельсинки). Публичные серверы — для умеренного
использования; запросы идут не чаще раза в секунду. Демо-маршрут считается на телефоне без интернета.

## Чего пока нет

- **Пробки, перекрытия и ремонты в реальном времени.** Для них нужен поставщик данных о дорожной обстановке (например,
  TomTom или HERE) и его ключ; бесплатного источника без ключа на всю Европу нет. Сейчас учитывается только то, что
  отражено в OpenStreetMap: дороги, закрытые для движения или строящиеся, сервер маршрутов не использует.
- Прогноз погоды на время проезда (используется текущая погода).
- Точные тарифы по участкам платных дорог и особые платные объекты.

## Сборка

Нужен Flutter 3.47+ и Android SDK.

```bash
flutter pub get
flutter test                  # маршрутизатор, страны и тарифы, дальние маршруты, погода, навигация, экран
flutter build apk --release   # build/app/outputs/flutter-apk/app-release.apk
```

На GitHub сборка идёт автоматически (*Actions → Android APK*); APK публикуется в релиз `apk-latest`.

## Ключ подписи (чтобы обновлять приложение, не удаляя его)

Android ставит новую версию поверх старой, только если обе подписаны одним ключом. Ключ хранится в секрете
GitHub `ANDROID_SIGNING_KEY` (не в репозитории: иначе любой, кто видит код, мог бы выпускать «обновления» вашего
приложения). Значение секрета — текст из двух частей: первая строка — пароль, дальше — файл ключа в base64.

Создать ключ — один раз: `./tools/create-signing-key.sh папка` (нужна Java). Скрипт создаст файл
`ANDROID_SIGNING_KEY.txt`; его содержимое целиком вставляется в секрет: *Settings → Secrets and variables → Actions →
New repository secret*. **Сохраните этот файл** — это и есть ключ: без него обновление поверх установленной версии
станет невозможным.

Без секрета CI собирает APK с временным ключом и предупреждает об этом. В логе каждой сборки печатается отпечаток
подписи (SHA-256) — у всех сборок с постоянным ключом он одинаковый. Номер версии растёт автоматически (номер запуска CI).

## Структура

| Путь | Назначение |
|---|---|
| `lib/core/` | граф дорог, поиск маршрута (A\* по времени и плате), страны и границы, модель платы, погода |
| `lib/engine/` | серверы маршрутов (Valhalla, OSRM), участки и обход стран вне ЕС, стоимость, Open-Meteo, фоновый поток; локальный граф для демо |
| `lib/ui/` | карта, поиск, карточка маршрута, ведение по маршруту |
| `assets/geo/` | границы стран Европы (Natural Earth 1:10m; собирается `tool/build_geo.py`) |
| `assets/tariffs/` | цены: `countries.json` (схемы стран) и файлы операторов (см. `tool/README.md`) |
| `test/` | тесты, в том числе синтетические сети через несколько стран |

## Ограничения

- Границы стран известны с точностью около километра, поэтому дорога считается «вне ЕС», только если уходит за границу
  глубже чем на ~1,5 км.
- Какие дороги требуют виньетку, определяется по классу дороги (магистрали и скоростные шоссе; в Румынии и Болгарии —
  ещё и главные дороги). Это приближение к правилам стран.
- Нет данных о пробках: время — по модели сервера маршрутов с поправкой на погоду.
- Ограничения скорости серверы не отдают, поэтому знак ограничения на экране ведения не показывается.
- Публичные серверы Valhalla, OSRM, Nominatim, Open-Meteo и тайлы OSM — для умеренного использования.
