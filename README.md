# 🧭 Cargo Navigation

Android-навигатор на **Flutter**, который строит **самые быстрые маршруты с минимальными затратами на дорогу**
и позволяет выбирать дороги по типу, ограничению скорости и платности.

## Возможности

- **Реальные дороги** OpenStreetMap (Overpass API), карта — `flutter_map`, поиск адресов — Nominatim, точки ставятся кликом, долгим нажатием или поиском, есть геолокация.
- **Платные / бесплатные дороги:** комбинировать оптимально · только бесплатные · предпочитать платные.
- **Типы дорог:** магистрали, шоссе, главные, второстепенные, местные, жилые улицы, дворы — включаются по отдельности.
- **Ограничения скорости:** не ездить по дорогам с лимитом ниже/выше заданного (тег `maxspeed`), потолок скорости вашего авто.
- **Минимум затрат:** стоимость = `время × цена вашего часа + платные участки + топливо`. Переключатель «Быстрее / Баланс / Дешевле» меняет цену часа. Топливо считается с учётом скорости.
- **Альтернативы на фронте Парето:** «самый быстрый», «самый дешёвый» и «оптимальный для ваших настроек» — с разбивкой времени, платных дорог и топлива.
- **Навигация в пути:** пошаговые подсказки, голос (Android TTS), знак ограничения скорости, остаток пути/времени/расходов, перестроение при уходе с маршрута, работа при выключенном экране (foreground-служба геолокации). Есть симуляция движения.

## Маршруты любой длины (> 600 км)

Одна рамка вокруг A и B для дальних маршрутов не работает: Overpass ограничивает объём данных. Поэтому
`lib/engine/engine.dart` строит маршруты иерархически:

1. **До 120 км** — одна загрузка области (как раньше).
2. **Дальше — каркас.** Грузятся только магистрали и шоссе в **коридоре вдоль линии A→B** (запрос `around`), **кусками по ~150 км**; ширина коридора — 8% дистанции (15–70 км). Если связности нет (например, при режиме «только бесплатные»), ступенчато добавляются главные и второстепенные дороги, а коридор расширяется до 150 км. Если участок запроса не отвечает — он делится пополам и повторяется.
3. **Уточнение.** По найденному маршруту грузится узкий коридор (±3 км) со всеми разрешёнными типами дорог, и маршрут пересчитывается — подтягиваются обходы, местные дороги и альтернативы.
4. Рядом со стартом и финишем всегда загружаются все мелкие дороги.

Загрузка, разбор JSON и расчёт идут в фоновом изоляте, поэтому интерфейс не зависает; есть прогресс по участкам и кнопка «Отмена». Граф хранится между запросами: смена настроек и перестроение не качают данные заново. Лимит — 6000 км по прямой.

## Сборка

Нужен Flutter 3.47+ и Android SDK.

```bash
flutter pub get
flutter test                  # маршрутизатор, дальние маршруты, навигация, UI
flutter build apk --release   # build/app/outputs/flutter-apk/app-release.apk
```

На GitHub сборка идёт автоматически (*Actions → Android APK*); APK публикуется в релиз `apk-latest` и в артефакты запуска.

## Ключ подписи (чтобы обновлять приложение, не удаляя его)

Android обновляет приложение поверх установленного, только если подпись совпадает. Пока ключ не задан, CI подписывает
APK временным ключом, который каждый раз новый, и приходится удалять приложение. Постоянный ключ создаётся **один раз**:

1. На своём компьютере (нужна Java) выполните `./tools/create-signing-key.sh` — он создаст файл ключа и напечатает 4 значения.
   **Сохраните файл ключа** (потеряете — придётся один раз переустановить приложение).
2. В GitHub: *Settings → Secrets and variables → Actions → New repository secret* — создайте секреты
   `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` со значениями из вывода скрипта.
3. Запустите сборку (*Actions → Android APK → Run workflow*). Дальше все сборки подписываются этим ключом, а номер версии
   растёт сам (`versionCode` = номер запуска), поэтому новые APK ставятся поверх старых.

Ключ намеренно **не хранится в репозитории**: иначе любой, кто видит репозиторий, мог бы выпускать «обновления» вашего приложения.
Первую установку после настройки ключа придётся сделать с удалением старой версии — один раз.

## Структура

| Путь | Назначение |
|---|---|
| `lib/core/` | граф дорог на типизированных массивах, A\* с обобщённой стоимостью, фронт Парето, пошаговые инструкции |
| `lib/engine/` | загрузка данных (Overpass), логика коротких и дальних маршрутов, фоновый изолят, демо-данные |
| `lib/ui/` | карта, настройки, карточки маршрутов, контроллер навигации |
| `test/` | тесты, в т.ч. синтетическая сеть на ~1500 км, имитирующая Overpass |

## Ограничения

- OpenStreetMap знает, **какие дороги платные, но не тарифы** — ставки (за км и за въезд) задаются в настройках.
- Нет данных о пробках: скорость = лимит × поправочный коэффициент по типу дороги. Повороты и светофоры отдельно не учитываются.
- Публичные серверы Overpass и тайлы OSM — для умеренного использования. Дальний маршрут может занять несколько минут из-за загрузки; для интенсивного использования стоит поднять собственный Overpass и тайл-сервер.
- Для Google Play потребуется отдельная настройка (App Signing, формат AAB).
