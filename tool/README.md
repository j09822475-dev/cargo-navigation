# Тарифы платных дорог

Приложение считает стоимость платных участков по ставке €/км. Ставка берётся из файлов `assets/tariffs/*.json`
(официальные данные операторов), а если оператора в них нет — из ваших настроек («по умолчанию»). Какая доля платных
километров посчитана по тарифам операторов, показывается в карточке маршрута.

## Как добавить оператора

1. Соберите таблицу участков (CSV): `ref,length_km,price_eur` — номер дороги (тег `ref` в OpenStreetMap), длина участка
   и цена для легкового авто с официальной страницы/PDF оператора.
2. Импортируйте:
   `dart run tool/import_tariffs.dart --operator "Оператор" --alias "значение тега operator в OSM" --country FR --updated ГГГГ-ММ-ДД --source "URL" участки.csv > assets/tariffs/оператор.json`
3. Добавьте имя файла в `assets/tariffs/index.json` → `{"files": ["оператор.json"]}`.

Связь с картой идёт по тегам OSM `operator` и `ref` платной дороги; значение `--alias` должно совпадать с тегом `operator`
(можно несколько `--alias`). Для замкнутых систем (въезд → выезд) ставка получается как цена ÷ длина участка — точна для
целых участков и приближённа между развязками.

Файлы с некорректными данными пропускаются. Тарифы меняются обычно раз в год — обновляйте `--updated` и `--source`.

## Что делать, если в данных оператора нет номеров дорог (`ref`)

Так устроен набор APRR: тарифы заданы по станциям (`libelle_gare_entree`/`libelle_gare_sortie`) с тарифной дистанцией, без
`ref` и координат. Тогда делается одна ставка на оператора: CSV с пустой колонкой `ref`, `length_km` = `distance_tarifaire_km`,
`price_eur` = `tarif_classe_1` (легковые). Ставка получается взвешенной по длине. Это приближение: у отдельных участков
(тоннели, горные дороги) она заметно выше средней. Описывайте разброс в `--note`. Для большей точности нужны координаты
станций, чтобы привязать цену к участкам карты.

Пример (AREA): `assets/tariffs/area.json`.
